
# Tim Dev — Web Profile

## Deskripsi Proyek

Tim Dev Web Profile merupakan website profil tim pengembang
yang dibuat menggunakan framework Laravel 12.

Website ini dikembangkan untuk memperkenalkan identitas tim,
informasi, hasil karya, keahlian, dan kontak tim.

## Cara Menjalankan Proyek

### 1. Clone repository

```bash
git clone https://github.com/dafaanggara123/web-profile-kelompok.git
```

### 2. Masuk ke folder proyek

```bash
cd web-profile-kelompok
```

### 3. Install dependency

```bash
composer install
```

### 4. Salin file environment

```bash
copy .env.example .env
```

### 5. Buat application key

```bash
php artisan key:generate
```

### 6. Siapkan database

Sesuaikan konfigurasi database pada file .env.

Jika menggunakan SQLite, siapkan file database
dan jalankan:

```bash
php artisan migrate
```

### 7. Jalankan Laravel

```bash
php artisan serve
```

Buka browser:

http://127.0.0.1:8000
